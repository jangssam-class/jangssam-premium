# 장쌤의과외교실 Premium

장쌤의과외교실 공식 홈페이지입니다.

## 주요 페이지

- `index.html` 메인 홈페이지
- `blog.html` 교육정보 목록
- `post.html?slug=...` 교육정보 상세 글
- `admin/` 관리자 포스팅 화면
- `상담신청.html` 상담 신청
- `지역별과외찾기.html` 지역별 과외 안내
- `화상수업.html` 화상수업 안내

## 운영 방식

관리자에서 작성한 글은 `content/posts.json`과 `이미지/blog`에 저장되고 GitHub 커밋 후 Netlify가 자동 배포합니다.

장쌤 Premium 게시글 AI/SEO 자동화 패치

[이 패치를 한 번 적용한 뒤부터]
관리자(/admin)에서 새 게시글을 작성하고 '공개'로 저장하면:
1. content/posts.json이 GitHub에 저장됩니다.
2. Netlify가 자동으로 npm run build를 실행합니다.
3. /posts/주소용영문이름.html 정적 게시글이 자동 생성됩니다.
4. title / description / canonical / Open Graph가 자동 생성됩니다.
5. Article + Breadcrumb 구조화 데이터가 자동 생성됩니다.
6. 'AI 검색 핵심답변'이 자동으로 '한눈에 답하기' 영역에 표시됩니다.
   - 비워두면 '목록 요약'이 자동으로 사용됩니다.
7. FAQ를 입력한 글은 FAQ 화면 + FAQPage 구조화 데이터가 자동 생성됩니다.
8. sitemap.xml에 새 게시글 URL이 자동 추가됩니다.
9. rss.xml에 새 게시글이 자동 추가됩니다.
10. 메인페이지 최신 교육정보 카드도 자동 갱신됩니다.
11. 교육정보 목록 링크도 새 정적 게시글 URL을 자동 사용합니다.

[앞으로 게시글마다 GitHub 파일을 수동 수정할 필요 없음]
관리자에서 글 작성 → 저장 → Netlify 배포 완료 확인만 하면 됩니다.

[새 글 작성 권장 항목]
- 주소용 영문 이름: 예) middle-school-english-vocabulary
- 제목
- 작성일
- 카테고리
- 목록 요약: 검색결과에 쓸 1~2문장
- 대표 이미지 / 이미지 설명
- 본문
- AI 검색 핵심답변: 가능하면 2~4문장 (비워도 자동 처리)
- 자주 묻는 질문: 필요할 때 3~5개

[주의]
- '주소용 영문 이름(slug)'은 다른 게시글과 절대 중복시키지 마세요.
- 저장 후 보통 Netlify Production deploy가 Published가 되면 실제 사이트에도 적용됩니다.

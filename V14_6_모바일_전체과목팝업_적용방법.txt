장쌤 홈페이지 V14.6 모바일 전체 과목 팝업

적용 방법
1. 이 압축파일을 풉니다.
2. 내부 파일과 폴더 전체를 GitHub jangssam-premium 저장소 최상단에 업로드합니다.
3. 같은 이름의 파일은 덮어쓰고 Commit changes를 누릅니다.
4. Netlify 배포가 Published가 된 뒤 모바일에서 확인합니다.

변경 내용
- 모바일 과목 영역에는 검정고시, 코딩, 수학 3개를 대표로 표시
- 아래에 전체 과목 보기 버튼 추가
- 버튼 클릭 시 수학, 영어, 국어, 과학, 사회, 역사, 논술, 코딩, 검정고시, 맞춤 커리큘럼 표시
- 과목 선택 시 기존 과목 상세 안내 팝업과 연결
- 배경 및 닫기 버튼, ESC 키로 팝업 닫기 가능
- PC 화면은 기존 구조 유지

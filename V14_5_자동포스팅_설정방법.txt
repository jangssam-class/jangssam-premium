장쌤 홈페이지 V14.5 자동 포스팅 운영방법

[이번 버전의 차이]
기존 관리자 편집기처럼 posts.json을 다운로드하여 GitHub에 다시 올리지 않습니다.
/admin/에서 저장하면 Decap CMS가 Git Gateway를 통해 content/posts.json을 GitHub main 브랜치에 직접 커밋합니다.

[최초 1회 Netlify 설정]
1. Project configuration > Identity에서 Identity 활성화
2. Identity > Registration을 Invite only로 설정
3. Identity > Users에서 본인 이메일 초대 및 비밀번호 설정
4. Identity > Services > Git Gateway > Enable Git Gateway

[글 작성]
1. https://jangssam-premium.netlify.app/admin/ 접속
2. 초대한 이메일과 비밀번호로 로그인
3. 교육정보 포스팅 > 포스팅 관리 선택
4. 포스팅 목록에서 새 항목 추가
5. 제목, 주소용 영문 이름, 요약, 본문 등을 입력
6. 오른쪽 위 저장 또는 발행 버튼 클릭
7. GitHub 저장소의 content/posts.json에 자동 커밋됨
8. Netlify 자동 배포 후 blog.html과 post.html에 반영됨

[중요]
- Git Gateway가 켜져 있지 않으면 저장할 수 없습니다.
- Netlify 운영 크레딧이 소진되어 Production deploy가 일시 중지된 경우 GitHub에는 글이 저장되어도 실제 사이트 반영은 다음 결제 주기 또는 배포 재개 후 이루어집니다.
- Git Gateway는 Netlify에서 deprecated로 표시되지만, 이미 활성화된 사이트에서는 현재 계속 동작합니다.
- 주소용 영문 이름은 중복 없이 영문 소문자, 숫자, 하이픈만 사용하세요.

[정상 확인]
- 저장 후 GitHub > content/posts.json의 최근 커밋 시간이 바뀌는지 확인
- Netlify Deploys에서 새 Production deploy가 Published가 되는지 확인
- https://jangssam-premium.netlify.app/blog.html에서 새 글 확인
